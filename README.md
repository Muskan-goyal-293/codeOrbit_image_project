# 📸 codeOrbitImgGalry

### codeOrbit Internship – Project 3

A responsive Image Gallery web application built using HTML, CSS, and JavaScript. The project allows users to search images from the Pexels API, preview images, save favorites using Local Storage, switch themes, and navigate through paginated results.
</div>


## ✨ Features

* 🔍 Search images using Pexels API
* 📄 Pagination support
* ❤️ Save favorite images
* 💾 Local Storage integration
* 🌙 Dark / Light theme toggle
* 🖼️ Image preview overlay
* 📱 Fully responsive design
* ✨ Smooth hover effects and transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Pexels API
* Local Storage


## 🎯 Internship Requirements Covered

✔ Create an image gallery using HTML and CSS layout

✔ Use JavaScript for image navigation

✔ Add hover effects and transitions

✔ Ensure mobile responsiveness

✔ Add image search functionality using API

✔ Implement image saving using Local Storage

✔ Add pagination support
